# Score only subclasses 189, 190, and 491

The Points Test in Schedule 6D applies to SkillSelect subclasses 189, 190, and 491. Other skilled visas (482, 186, 485, 191, 494, 407, 887) will get a later Visa Overview: description only, never a Total Score. Eligibility Check and Invitation Advisor are also out of this phase.
